# 烟台毓璜顶医院一代试管短方案详细促排流程是怎样的？

> 更新时间：2026-09-11 (UTC+8)

有性生活三年，备孕两年没有怀上，有做过子宫输卵管造影，结果是双侧输卵管阻塞。疏通了效果也不好，现在正在烟台毓璜顶医院做一代试管婴儿，昨天做完所有的身体检查后，医生决定采用短方案经常促排取卵，我想了解下短方案详细促排流程是怎样的？

在烟台毓璜顶医院做一代试管婴儿，采用短方案促排卵，整个流程还是比较简单的，就是在月经的第2-3天开始使用促性腺技术帮助卵泡生长发育，在用药期间需要用b超监测卵泡发育情况，同时还需要抽血检查fsh、lh数值，在卵泡长到接近18mm的时候就可以打夜针，准备取卵手术了。至于说短方案促排几天才行，需要看患者身体情况决定，大部分人只需要用药10天左右就可以取卵。

烟台毓璜顶医院是当地非常出名的试管婴儿医院，支持一代、二代试管开展，同时还能进行供精、供卵试管助孕。在该院做试管，促排进程使用的方案有长方案、超长方案、短方案、拮抗剂方案、微刺激方案等等，其中试管短方案详细促排流程如下：

- 1. 女性在月经期间到医院做性激素6项、b超检查，判断患者的卵巢功能，确定可以是用短方案；
- 2. 月经来潮第2-3天，开始使用促性腺激素类药物进行促排卵，药物可以是普丽康、贺美奇、果纳芬或丽申宝；
- 3. 在促排的第5-6天、第8-9天通过B超检测卵泡发育情况，抽血测定相应激素含量的变化，然后调整药物用量，并确定夜针注射时间；
- 4. 当卵泡都长到了17mm以上，就可以开始注射夜针hcg了，注射后36小时即可进行取卵。
烟台毓璜顶医院做一代试管并不是所有患者都会使用短方案，至于说短方案适合哪些人群，一般都是高龄、既往常规方案促排卵数量≤3枚，以及卵巢储备功能下降等患者，其使用短方案促排可以获得较多的卵泡，提高妊娠概率。
